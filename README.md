# 🔐 Gerador de Senhas AMP

Um gerador de senhas desenvolvido para facilitar e agilizar a criação de senhas com diferentes requisitos.

## 📌 Sobre o projeto

Este projeto surgiu a partir de uma necessidade real no meu ambiente de trabalho.

Durante algumas atividades, era necessário criar senhas manualmente para diferentes sistemas, seguindo requisitos como quantidade de caracteres, letras maiúsculas e minúsculas, números e caracteres especiais.

Como essa era uma tarefa repetitiva e consumia tempo, criei este gerador utilizando Inteligência Artificial para automatizar esse processo e facilitar a criação das senhas.

## ⚙️ Funcionalidades

- Escolha do tamanho da senha entre **4 e 12 caracteres**;
- Geração automática de senha aleatória;
- A senha gerada possui:
  - Pelo menos uma letra maiúscula;
  - Pelo menos uma letra minúscula;
  - Pelo menos um número;
  - Pelo menos um caractere especial;
- Botão para copiar a senha gerada;
- Interface responsiva.
